# 99 Names of Allah Learning Tracker

A simple static web page for learning the 99 Names of Allah, setting a daily goal, tracking progress, and practicing with a quiz.

## Features

- Browse the 99 Names with transliteration and English meanings
- Set a daily learning goal
- Mark names as learned for the day
- Local browser progress saving
- Multiple-choice practice quiz

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/(root)` folder, then save.
